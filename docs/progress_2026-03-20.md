## What Doesn't Work

### Doom
- loader.prg runs REU DMA correctly
- Crashes at `JML [$04FC]` (opcode $DC = indirect long jump)
- Either JML not implemented in P65C816, or target address wrong
- Next: test JML independently, check $04FC contents

### Speed Bottlenecks
- Real-world speed ~4MHz despite 34x tight-loop benchmark
- I/O reads (VIC $D012, CIA timers) go through 1MHz SDRAM path
- All writes go through SDRAM (cache is read-only)
- Cache misses on first access to new code regions
- 1-cycle suppress halves per-slot cache throughput

### Same-Line Suppress-Skip
- Wide cache line infrastructure ready (64-bit word, same_line signal)
- Skipping the suppress crashes CPU with garbage execution
- Root cause: likely setup time violation on combinational cache_di path
- Needs SignalTap or simulation to diagnose

## Architecture Overview

```
SDRAM Memory Map (32MB):
  0x0000000  Bank $00 C64 RAM (64KB)
  0x0100000  CRT cartridge ROMs (1MB)
  0x0200000  TAP tape images (1MB)
  0x1000000  REU / SuperRAM (16MB)
              ├─ Bank $01 → REU+$010000
              ├─ Bank $02 → REU+$020000 (doom.reu data starts here)
              └─ Bank $FF → REU+$FF0000

Bus Cycle Allocation (32 slots per rotation):
  EXT0-3:  Cache hits enabled (turbo only)
  DMA0-3:  REU DMA or blocked
  EXT4-7:  Cache hits enabled (turbo only)
  VIC0-3:  VIC reads only (always blocked for cache)
  CPU0-F:  Cache hits + SDRAM pipeline
```
